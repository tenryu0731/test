# サン・ジミニャーノ市街戦（San Gimignano Streets）

昼下がりのトスカーナの丘上都市サン・ジミニャーノを舞台にした、一人称視点の 3D シューティングです。
街の中にいる訓練用ロボット 5 体をすべて停止させるとクリアです。スマートフォンでのプレイを主な対象にしています。

街並みは実在の町の雰囲気を表現したもので、実際の街の正確な再現ではありません。
テクスチャ・モデル・音はすべてコードで生成しています（画像・音声ファイルは使っていません）。

## 遊び方

1. 開始画面で操作説明を読み、「出撃する」を押します。
2. 石畳の路地や広場を移動しながらロボットを探して撃ちます（頭部は 2 倍のダメージ）。
3. ロボット 5 体を停止させると勝利、HP が 0 になると敗北です。どちらの画面からも「もう一度」で再挑戦できます。

### 操作

| 操作 | スマートフォン | パソコン |
|---|---|---|
| 移動 | 画面左側をドラッグ（仮想スティック。大きく倒すとダッシュ） | W A S D ／ 矢印キー |
| 視点 | 画面右側をドラッグ | マウス |
| 射撃 | 「射撃」ボタンを押し続ける（押したままドラッグで狙いを調整） | 左クリック（押し続けで連射） |
| リロード | 「リロード」ボタン | R |
| ジャンプ | 「ジャンプ」ボタン | Space |
| ダッシュ | スティックを大きく倒す | Shift |
| 一時停止 | 左上の一時停止ボタン | Esc |

一時停止画面で視点感度を変更できます。スマートフォンでは開始時に全画面・横向きへの切り替えを試みます。

## 実行方法

ES モジュールを使っているため、HTML ファイルを直接開くのではなく、このフォルダを Web サーバーで配信して開きます。

```sh
cd european-street-fps
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

スマートフォンで遊ぶには、このフォルダを GitHub Pages などの静的ホスティングに置いてアクセスします。
three.js はフォルダ内（`vendor/`）に同梱しているので、外部の CDN には依存しません。

URL パラメータ（主に開発・検証用）:

- `?q=low` 影の解像度を下げる（性能の低い端末向け）
- `?touch` マウス環境でもタッチ操作 UI を表示する
- `?autostart` 開始画面を飛ばしてすぐに始める

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` | エントリーポイント（import map で `vendor/` の three.js を読み込む） |
| `js/main.js` | 描画設定、空と太陽光、影、プレイヤー移動、射撃判定、ゲーム進行（開始・勝敗・リスタート・一時停止）、解像度の自動調整 |
| `js/physics.js` | 建物との衝突判定（AABB とグリッド）、レイキャスト、視線判定 |
| `js/textures.js` | 手続き生成の PBR マテリアル（石畳、ヘリンボーンのレンガ、漆喰、石積み、テラコッタ瓦、鎧戸など） |
| `js/city.js`, `js/city-geo.js` | 街の生成：広場と噴水、ロッジア、大通り、大聖堂前広場と鐘楼、路地とトンネル状の通路、塔、城門、背景の丘と糸杉 |
| `js/weapon.js` | 一人称のカービン銃と腕、反動・リロードのアニメーション、マズルフラッシュ、薬莢、着弾エフェクト |
| `js/enemies.js` | 訓練用ロボット（モデル、歩行アニメーション、巡回・発見・追跡・射撃の AI、被弾・停止の演出） |
| `js/input.js` | タッチ操作（仮想スティック、視点ドラッグ、ボタン）とキーボード・マウス操作 |
| `js/ui.js`, `css/style.css` | HUD（HP・弾数・残り敵数・照準・被弾方向表示）と各画面（開始・一時停止・勝利・敗北） |
| `js/audio.js` | Web Audio による効果音の合成 |
| `docs/CONTRACT.md` | モジュール間のインターフェース仕様（並行開発に使用） |
| `tools/shot.mjs` | ヘッドレス Chromium でスクリーンショットを撮る開発用スクリプト |
| `vendor/` | three.js r170（MIT ライセンス、`vendor/LICENSE-three.txt`） |
