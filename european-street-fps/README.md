# サン・ジミニャーノ市街戦（San Gimignano Streets）

昼下がりのトスカーナを舞台にした、一人称視点の 3D シューティングです。
城壁に囲まれた丘上都市サン・ジミニャーノと、その周りに広がる約 1.4 km 四方の田園（ぶどう畑、オリーブ畑、糸杉の並木、川と湖、教会・城塞・修道院・農家などのランドマーク）を自由に歩き回り、各地に配置された訓練用ロボットの部隊と、田園を巡回する敵の訓練戦車・訓練ヘリをすべて撃破するとクリアです。戦車やヘリコプターに乗って戦うこともできます。
スマートフォンでのプレイを主な対象にしています。

街並みは実在の町の雰囲気と塔の名前を借りたもので、正確な再現ではありません。田園のランドマークは架空の配置です。
テクスチャ・モデル・音はすべてコードで生成しています（画像・音声ファイルは使っていません）。

## 遊び方

1. 開始画面で難易度を選び、操作説明を読んで「出撃する」を押します。
2. 画面上部の目標表示・コンパス・ミニマップを頼りに、街の広場や田園のランドマークにいるロボットの部隊を探して撃ちます（頭部は 2 倍のダメージ）。
3. 塔や見張り台の足元で「登る」と、上から街や田園を見下ろせます。登ると周辺の部隊の位置が地図に表示されます。
4. 道中の木箱から弾薬と救急キットを拾えます。
5. ロボットの部隊をすべて停止させると、目標が残りの敵車両に切り替わります（地図では戦車が四角、ヘリがひし形）。
6. 全ロボットと全敵車両を撃破すると勝利、HP が 0 になると敗北です。どちらの画面からも「もう一度」で再挑戦できます。

一時停止画面から「地図」（全体地図。クリックで目的地を設定）と「俯瞰モード」（ゲームを止めて上空から自由に街と田園を眺める）を開けます。

### 乗り物と車両戦

| | 場所 | 武装 | 特徴 |
|---|---|---|---|
| ヘリコプター | 南門を出てすぐ西のヘリポート | 機関砲（連射）、ロケット弾 16 発（3 秒に 1 発ずつ補充） | 町の上や田園を自由に飛べる。地面・広場・ヘリポートに着陸して降りる（屋根や水面の上ではホバリング） |
| 戦車 | 東門を出てすぐ南の駐車場 | 主砲（約 2.4 秒ごとに 1 発、爆風あり）、機銃 | 砲塔は視点の向きに回る。いつでも降りられる。深い湖には入れない |

- 乗り物の中ではプレイヤーではなく車体が弾を受けます。装甲は画面の「装甲 %」で、0 になると車両が壊れ、プレイヤーは外に投げ出されて体力も減ります。壊れた乗り物は 45 秒後に元の場所に補充されます。
- 戦車はロボットの小銃弾をほとんど受け付けませんが、敵戦車の砲弾と敵ヘリの攻撃には弱くなります。
- 敵の訓練戦車（灰色にオレンジの帯）は田園の道を巡回し、見つけた相手を主砲で撃ちます。敵の訓練ヘリは町の周りを飛び、機関砲と対戦車ロケットで攻撃します。
- 小銃でも敵車両は壊せますが時間がかかります。戦車やヘリで戦うのが有効です。照準の近くに敵車両があると、車両の武器は自動でその中心を狙います。
- 敵の数（ふつう）: ロボット 32 体、戦車 3 台、ヘリ 2 機。難易度で増減します（ストーリー 17 体と 3 台、エキスパート 54 体と 8 台）。

### 難易度

| 難易度 | 内容 |
|---|---|
| ストーリー | 景色と探索を楽しむ。敵は少なく、体力はすぐ回復する |
| やさしい | 敵が少なく弱い。体力が自然回復する |
| ふつう | 標準の難しさ。体力は少しずつ回復する |
| むずかしい | 敵が多く正確。体力は回復しない |
| エキスパート | 敵は多く硬く、弾薬も少ない |
| カスタム | 敵の数・敵の強さ・被ダメージ・回復・弾薬を 5 段階ずつ個別に調整 |

難易度は開始画面か設定画面で変更できます（プレイ中に変えると最初からやり直し）。

### 操作

| 操作 | スマートフォン | パソコン |
|---|---|---|
| 移動 | 画面左側をドラッグ（仮想スティック。大きく倒すとダッシュ） | W A S D ／ 矢印キー |
| 視点 | 画面右側をドラッグ | マウス |
| 射撃 | 「射撃」ボタンを押し続ける（押したままドラッグで狙いを調整） | 左クリック（押し続けで連射） |
| 狙う（照準器を覗く） | 「狙う」ボタン（切り替え） | 右クリック（押している間） |
| 覗く（壁から顔を出す） | 左上の「左」「右」ボタン（切り替え） | Q ／ E（押している間） |
| リロード | 「リロード」ボタン | R |
| ジャンプ | 「ジャンプ」ボタン | Space |
| ダッシュ | スティックを大きく倒す | Shift |
| 塔に登る・降りる | 足元で表示されるボタン | F |
| 乗り物に乗る・降りる | 近くで表示されるボタン（ヘリは着陸中のみ降りられる） | F |
| ヘリの操縦 | 左スティックで前後左右（大きく倒すと加速）、右側ドラッグで向き、「上昇」「下降」ボタン | W A S D で前後左右、マウスで向き、Space 上昇、C（または Ctrl）下降、Shift 加速 |
| ヘリの武器 | 「機関砲」「ロケット」ボタン | 左クリック 機関砲、右クリック ロケット |
| 戦車の操縦 | 左スティックで前進・後退・旋回、右側ドラッグで砲塔の向き | W / S 前進・後退、A / D 旋回、マウスで砲塔 |
| 戦車の武器 | 「主砲」「機銃」ボタン | 左クリック 主砲、右クリック 機銃 |
| 地図 | ミニマップをタップ | M ／ Tab |
| 一時停止 | 左上の一時停止ボタン | Esc |

俯瞰モードでは、ドラッグで回転、右ドラッグ（または WASD）で移動、ホイールで拡大縮小します。
設定画面で難易度・画質（低／中／高）・視点感度・音量を変更できます（ブラウザに保存されます）。

## 実行方法

ES モジュールを使っているため、HTML ファイルを直接開くのではなく、このフォルダを Web サーバーで配信して開きます。

```sh
cd european-street-fps
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

スマートフォンで遊ぶには、このフォルダを GitHub Pages などの静的ホスティングに置いてアクセスします。
three.js はフォルダ内（`vendor/`）に同梱しているので、外部の CDN には依存しません。

URL パラメータ（主に開発・検証用）:

- `?q=low` / `?q=medium` / `?q=high` 画質を指定する（省略時はスマートフォンで中、パソコンで高）
- `?touch` マウス環境でもタッチ操作 UI を表示する
- `?autostart` 開始画面を飛ばしてすぐに始める
- `?nomap` 起動時の地図画像の生成を省く（検証用）
- `?debug` 描画負荷（ドローコール数・ポリゴン数・フレーム時間）を表示する

| `js/layout.js` | 世界の配置（町の範囲と城門、ランドマークの位置、道・川・湖、開始位置） |
| `js/world.js` | 地形・町・ランドマークを組み立て、衝突・経路点・敵配置・展望ポイントをまとめる |
| `js/terrain*.js` | 田園：高さ、畑の区画、道と川、地面のシェーダー、樹木・ぶどう・草花、湖と川の水面、石垣 |
| `js/city*.js`, `js/textures.js` | 町：街区と建物、塔、教会と広場、城壁と城門、小物、手続き生成の PBR マテリアル |
| `js/landmarks*.js` | 田園のランドマーク（教区教会、城塞、修道院、ヴィラ、水車小屋と石橋、農家、礼拝堂、見張りの塔、採石場） |
| `js/render*.js` | 描画：物理ベースの空と雲、空からの環境光、遠景のかすみ、影、画質ごとの後処理、デバッグ表示 |
| `js/physics.js` | 衝突判定（AABB とグリッド、地形の高さ）、レイキャスト、視線判定 |

| `js/enemies*.js` | 訓練用ロボット 3 種（モデルとアニメーション、経路探索、巡回・発見・追跡・射撃の AI、被弾・停止の演出） |

| `js/pickups.js` | 弾薬・救急キットの木箱 |
| `js/helicopter.js` | ヘリコプター（手続き生成のモデル、ヘリポート、飛行と着陸、建物との衝突、機関砲とロケット、撃墜） |
| `js/tank.js` | 戦車（手続き生成のモデル、走行と斜面の姿勢、砲塔と主砲、駐車場） |
