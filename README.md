作品の詳細・実行方法は各フォルダの README を見てください（スクリプトは各作品フォルダをカレントディレクトリにして実行します）。

| [`lumen/`](lumen/) | **LUMEN** — キリスト教の信仰を描く 60 秒のセリフなし短編 | 2D アニメーション（動画） |
| [`european-street-fps/`](european-street-fps/) | **サン・ジミニャーノ市街戦** — 昼のトスカーナの丘上都市と周辺の田園で訓練用ロボットの部隊を停止させる | 3D FPS（ブラウザ、スマホ対応、難易度選択） |

新しい作品を追加するときのルールは [`CLAUDE.md`](CLAUDE.md) にあります。
